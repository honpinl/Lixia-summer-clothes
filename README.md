# 立夏衣语 · 一条夏衣的千年时间轴

> 从《礼记·月令》的“天子始絺”，到空调房里的夏布新声——以时间为轴，看中国人夏天穿什么、为什么这样穿。

一个可直接打开的静态网站：纵向朝代时间轴 + 卷轴式史料阅读。内容取材于课程 PPT《立夏衣语——夏衣与节气民俗》，并据传世文献与公开资料校核、补充。

**纯静态 · 零依赖 · 无需构建 · MIT（代码）**

## 一、快速开始

### 1. 直接打开

双击 **index.html**，用 Chrome / Edge / Safari 打开即可。无需安装、无需构建、无需联网（字体使用系统字体）。

### 2. 本地服务（可选）

    cd lixia-yiyu
    python -m http.server 5173
    # 浏览器访问 http://127.0.0.1:5173

页面针对桌面（1440 / 1024）与手机（390）做了响应式适配。

### 3. 公网预览（ngrok）

双击 **scripts/start-public.bat**：自动启动本地 8080 静态服务与 ngrok 隧道，并打开 ngrok 面板（http://127.0.0.1:4040），复制其中的 https 地址即可分享。

- ngrok 免费版首次访问会出现一次“You are about to visit…”提示页，点 **Visit Site** 即可进入。
- 免费隧道地址在 ngrok 重启后会变化；长期展示建议用下面的 GitHub Pages。
- 关闭弹出的两个命令行窗口即停止服务。

### 交互

- 点击时代卡片（或键盘回车）→ 展开“卷轴”阅读该时代的**形制 / 材料 / 礼俗 / 史料原文 / 注释 / 关键词**。
- 卷轴内左右方向键切换上一卷 / 下一卷，Esc 合卷；卷底按钮同样可用。
- 顶部细金线为阅读进度；时间轴左侧金线随滚动点亮。
- 史料区的书影图版与“读某一卷”链接，可直接跳到对应时代。
- 尊重“减少动态效果”系统设置：开启后动画自动关闭。

## 四、部署到 GitHub Pages

仓库已内置 .github/workflows/pages.yml，推送 main 分支即自动部署。

1. 在 GitHub 新建仓库（例如 lixia-yiyu），不要勾选初始化 README。
2. 推送本地仓库：

       git remote add origin https://github.com/<你的用户名>/lixia-yiyu.git
       git push -u origin main

3. 打开仓库 **Settings → Pages**，把 **Source** 设为 **GitHub Actions**。
4. 等待 Actions 完成，访问 https://<你的用户名>.github.io/lixia-yiyu/ 。

站点全部使用相对路径（assets/...），因此部署在仓库子路径下也能正常加载，无需修改代码。

> 若只想用分支部署：Settings → Pages → Source 选 main / / (root)，仓库根目录已放置 .nojekyll。

## 五、史料与校勘说明

页面所有引文均标注出处，参考文献见站内“史料 · 参考文献”。几点需要说明：

1. **《礼记·月令》**：现存《礼记》由西汉戴圣编定，其中《月令》与《吕氏春秋·十二纪》关系密切；“孟夏之月……天子始絺”“立夏之日，天子亲帅三公、九卿、大夫以迎夏于南郊”均出此篇。
2. **《后汉书·礼仪志》**：“立夏之日，夜漏未尽五刻，京都百官皆衣赤，至季夏衣黄”是立夏服色制度最直接的记载；志的部分出自司马彪《续汉书》，站点参考文献按通行署名标注。
3. **《清嘉录》**：“立夏男女各试葛衣，云解蛀夏之疾”出自卷四“注夏”条所引《江震旧志》。这是**江南吴地的区域习俗**，页面已注明，不作全国性概括。
4. **《周礼·典枲》**：此句各本文字略有异同（“总 / 缌”“纻 / 紵”），站点从通行整理本，并在注释中说明。
5. **气候数据**（福建立夏均温 22.7℃、相对湿度 79.7%、降水 117.7 mm）来自课程 PPT 气候数据页，仅作区域示例。
6. **非遗信息**：重庆荣昌、江西万载夏布织造技艺于 2008 年列入国家级非物质文化遗产名录；湖南浏阳、四川隆昌夏布同样延续至今。
7. 部分内容属于**研究性表述**（如“夏布退出日常”“节气作为文化记忆”），已在正文中区分史料与解释。

## 六、设计说明

- **色**：取 PPT 的墨蓝荷塘为底（#061a23），以金（#c9a45c）、荷粉、宣纸色（#f5eddd）作点缀；卷轴内页用暖纸色与朱砂引文线，形成“夜塘—展卷”的明暗对照。
- **字**：标题与朝代用宋体（思源宋体 / 宋体），引文用楷体，界面小字用系统无衬线；不依赖外部字体文件。
- **图**：莲纹来自 PPT 素材，经抠底与边缘羽化后作为 hero 主视觉；史料图版为传世文献扫描页，保留纸张与朱笔痕迹。
- **动效**：水波扩散、莲影浮动、卷轴展开；全部为 CSS 实现，无第三方库。
